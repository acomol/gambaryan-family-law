# Восемь версий лендинга для сравнения

Собрано 6 августа 2026. Пересобрано из приватного артефакта в файл, чтобы работа
не терялась при передаче другому исполнителю.

Каждая версия отличается от боевой **ровно одним** — шрифтами, компоновкой
первого экрана или наличием мобильной панели. Всё остальное идентично, поэтому
разницу видно честно. Адреса постоянные: при пересборке ссылка не меняется,
обновляется содержимое.

## Как сравнивать

- **Открывать с телефона.** Тонкие штрихи Playfair на светлом фоне при мелком
  кегле теряются заметнее, чем на десктопе, а панель действий на десктопе не
  показывается вовсе.
- **Вес шрифта указан для кириллического поднабора** — того, что реально
  скачает русскоязычный посетитель. Латиницу он не грузит.
- **Покрытие кириллицы проверено по таблице символов каждого файла**, а не по
  названию поднабора: недобор в вариантах 3 и 4 — редкие символы вроде «Ѕ» и
  «Ѡ», в русском тексте они не встречаются.
- **Про мини-форму (вариант снят).** Пока он существовал, заявка не отправлялась:
  основная форма на сайте — заглушка, введённое переносилось вниз и никуда не
  уходило. Приём заявок остаётся неподключённым и для остальных версий.

## Что изменилось после сборки доски

7 августа владелец снял вариант `hero-c-miniform` (коммит `d332b14`): убран из
скрипта сборки вместе с исключением в проверке, которое существовало только ради
него — у C не было прямого пути к форме, потому что форма стояла прямо в hero.
Оба деплоя удалены с Cloudflare Pages. Остались варианты A и B, оба пересобраны,
проверки прошли. Итого живых адресов **восемь**, а не девять.

Все версии живут на постоянных адресах Cloudflare Pages и пересобираются одной
командой после любой правки основного сайта.
