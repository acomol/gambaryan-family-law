# Карта источников текста

**Версия:** `CONTENT-SOURCE-MAP v1.0.0`

**Дата:** `2026-08-11`

**Назначение:** не смешивать утверждённый клиентом текст, последующие прямые
правки владельца, служебные подписи интерфейса и нерешённые варианты.

## Правило приоритета

1. Последняя прямая правка владельца/клиента с зафиксированной датой имеет
   приоритет над более ранним документом только в явно названном блоке.
2. Для остальных смысловых текстов источник истины — клиентский документ.
3. `SYSTEM-UI` может объяснять действие или ошибку, но не должен добавлять
   новые юридические обещания, специализации или факты.
4. `OPEN` не изменяется автоматически: сначала заказчик выбирает формулировку,
   затем решение получает дату и новую версию этой карты.

## Категории

| Метка | Значение |
|---|---|
| `CLIENT-DOCUMENT` | Текст из утверждённого клиентского файла |
| `OWNER-OVERRIDE` | Более поздняя прямая правка владельца, ограниченная конкретным блоком/вариантом |
| `SYSTEM-UI` | Служебная подпись навигации, формы, ошибки или состояния интерфейса |
| `OPEN` | Есть два варианта либо нет решения о размещении; требуется явное согласование |

## Обновление карты

После ответа заказчика:

1. записать решение и дату в соответствующей строке;
2. перенести закрытую строку из `OPEN` в `CLIENT-DOCUMENT` или
   `OWNER-OVERRIDE`;
3. обновить версию и дату этой карты;
4. синхронизировать `docs/CONTENT-APPROVED.md`, `docs/CONTENT-MISSING.md` и
   `docs/CONTENT-EXTRA.md`;
5. менять source/generator, затем пересобирать Preview; не править `build/`
   вручную.
