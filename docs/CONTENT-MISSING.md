# Чего не хватает на сайте

Утверждённый клиентом текст, которому на странице пока нет места. Это не ошибки
переноса — переносить некуда: либо секции не существует, либо блок занят другим
решением.

**Проверено на:** `gambarian-landing.pages.dev`, коммит `017133d`, 2026-08-05.
**Статус:** ждёт решения клиента. После размещения строку убрать из этого файла.

---

## 1. Первый экран — заголовок и лид

| № | Утверждено | Сейчас на сайте |
| :---: | --- | --- |
| 1.7 | Развод в Израиле? Адвокат по семейному праву — на русском языке | Адвокат по семейному праву в Израиле |
| 1.8 | Развод без судебного спора и бракоразводные процессы · Брачный договор · Медиация · Алименты · Установление отцовства · Раздел имущества · Международные дела о возвращении детей · Адвокат Александр Гамбарян поможет понять, какие вопросы требуют решения сейчас и с чего начать — на русском языке. | Развод, раздел имущества, споры о детях. Более 30 лет практики, консультация на русском языке. |

**Почему не размещено.** Первый экран переработан позже документа: заголовок стал
короче, под ним появился отдельный подзаголовок. Утверждённая версия 1.8 — семь
направлений отдельными строками плюс завершающая фраза.

**Что это стоит по месту.** Семь строк вместо одной сдвигают кнопку «Записаться на
консультацию» вниз. На мобильном 390px она сейчас видна без прокрутки — после
добавления уйдёт за край экрана.

**Решение:** вернуть утверждённые 1.7 и 1.8, оставить нынешний вариант, или
разместить перечень из 1.8 ниже первого экрана отдельным блоком.

## 2. Секция «Подготовка к консультации» — отсутствует целиком

| № | Утверждено |
| :---: | --- |
| 6.6 | Если документы уже есть, подготовьте их названия и даты. Для имущественного вопроса полезно составить список основных активов и обязательств: Квартира · Ипотека · Счета · Пенсионные накопления · Бизнес · Долги |
| 6.9 | Если часть документов отсутствует, это не мешает ознакомительной консультации. Мы обговорим и уточним, какие материалы действительно нужны для дела. |
| 6.12 | Не отправляйте документы и конфиденциальные сведения через форму для назначения консультации. |

**Почему не размещено.** На сайте пять секций: первый экран, услуги, прецедент,
адвокаты, контакты. Блока о подготовке к консультации нет — его нужно создавать.

**Что это стоит по месту.** Ничего из существующего не сдвигает: это новая секция.
Логичное место — перед формой обращения. Если высота критична, блок сворачивается
в раскрывающийся «Как подготовиться к консультации» — в закрытом виде одна строка.

**Отдельно про 6.12.** Дословно та же фраза уже стоит на сайте — в блоке формы
(строка 7.23). При создании секции 6 её придётся либо продублировать, либо оставить
только в форме.

**Решение:** создавать секцию или нет.

## 3. Форма обращения — поле темы

**Почему не размещено.** Поле темы из формы убрано, вместо него добавлено поле
Email. Сейчас в форме три поля: Имя, Телефон, Email.

**Что это стоит по месту.** Одно поле или одна строка-подсказка — высоту страницы
почти не меняет.

**Решение:** вернуть поле темы вместо Email, добавить четвёртым, или оставить как
есть.
