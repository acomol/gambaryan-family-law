# Задание: фото адвокатов на мобильном −25% по высоте

> Исполнитель: Codex. Ветка: `claude/website-development-kb0fu0`.
> Область: только `site/styles.css`. Читать до старта: `docs/ERRORS.md`.

## Что просил владелец

На мобильной версии уменьшить обе фотографии в карточках адвокатов
(секция `#attorney`) примерно на 25%.

## Как делать

**Не** масштабировать картинку до 75% ширины — останутся поля по бокам.
Правильно: ширина остаётся 100%, режется высота окна.

Базовое правило (`.attorney-photo`, ~строка 967): `aspect-ratio: 4 / 5`
(высота = 1.25 × ширины), `object-fit: cover`, `object-position: center top`.

В мобильный блок `@media (max-width: 860px)` добавить:

```css
/* Фото адвокатов ниже на четверть (решение владельца 2026-08-10):
   4/5 → 16/15 = высота 0.9375 ширины вместо 1.25, ровно −25%.
   cover при center top срезает низ кадра (корпус), головы не трогает. */
.attorney-photo { aspect-ratio: 16 / 15; }
```

Десктоп не трогать.

**Уточнение от 2026-08-10 (после приёмки).** Исходное задание требовало «одно
правило, `object-position` не менять». При реализации выяснилось, что в исходном
кадре голова Александра ниже примерно на 5% высоты, и при срезе низа по `cover`
головы адвокатов встают на разной высоте — карточки выглядят несимметрично.
Поэтому добавлено второе правило, только для мобильного и только для первой
карточки:

```css
.attorney-card:first-child .attorney-photo { object-position: center 16%; }
```

Отклонение от буквы задания признано осмысленным и узаконено задним числом:
оно использует мобильный запас `cover` и не меняет ни пропорцию, ни десктоп.

## Приёмка

1. Браузером на 390×844: высота каждого фото ≈ 0.9375 × его ширины
   (замер `getBoundingClientRect`, допуск ±2px); лица обоих адвокатов
   полностью в кадре (скриншот обеих карточек); горизонтального
   переполнения нет.
2. 1280px: `aspect-ratio` вычисляется как `4 / 5` — десктоп не изменился.
3. После merge пересобрать и передеплоить все производные
   (`build-font-variants`, `build-hero-variants`, `build-action-bar`,
   `build-review-numbered`) — они копируют `site/`. DoD проекта:
   live-readback маркера правила на боевом и `review-numbered`.
