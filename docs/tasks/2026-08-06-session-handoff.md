## Что это за проект

Лендинг адвокатской практики «Гамбарян & Партнёры» (семейное право, Израиль,
русскоязычная аудитория). Статичный сайт — `site/index.html` + `site/styles.css`
+ `site/app.js`, без сборки. Публикуется на Cloudflare Pages, проект
`gambarian-landing`. Боевой адрес — `https://gambarian-landing.pages.dev/`
(`noindex`, боевой домен клиента `www.gambarian.com` пока не привязан).

Репозиторий изначально — шаблон клонирования сайтов (Next.js в `src/`), но для
этого лендинга Next.js не используется. Публикуется только папка `site/`.
**В `src/components/StickyBar.tsx` лежит чужая панель с контактами другого
сайта (`mhatty.com`)** — артефакт шаблона, в прод не попадает, но если кто-то
соберёт Next-приложение, чужие контакты уедут в билд. См.
`docs/ACTION-BAR-REVIEW.md`, раздел «Посторонняя панель».

## Деплой — как публиковать

```bash
export CLOUDFLARE_API_TOKEN=<токен, см. чат/переменные окружения сессии>
export CLOUDFLARE_ACCOUNT_ID=4799e9f76c607e036c430a148d06a80b
npx --yes wrangler@latest pages deploy site --project-name=gambarian-landing --branch=main --commit-dirty=true
```

`--branch=main` обязателен — без него wrangler возьмёт имя git-ветки и уйдёт в
превью, боевой адрес не обновится. Подробности и live-readback —
`docs/DEPLOY.md`.

После деплоя — **обязательное правило проекта**: живое чтение опубликованного
адреса как доказательство, не просто «запушено». См. `Definition of Done` в
`CLAUDE.md`/`AGENTS.md`.

Все варианты пересобираются одной командой после любой правки `site/`:

```bash
python3 scripts/build-font-variants.py     # → build/font-variants/*
python3 scripts/build-hero-variants.py     # → build/variants/hero-*
python3 scripts/build-action-bar.py        # → build/variants/action-bar
python3 scripts/build-review-numbered.py   # → build/variants/review-numbered
```

`build-review-numbered.py` собирает **одну** страницу (не набор вариантов):
102 бейджа, по одному на каждый смысловой блок текста, в формате «3.11».
Повторяющийся шаблонный текст (одинаковая кнопка/абзац в 8 карточках услуг)
помечен только на первом появлении — этого достаточно, чтобы клиент сослался
на номер в правке. Мобильное меню (дублирует шапку, скрыто по умолчанию) не
нумеруется. Каждая замена в скрипте проверяется по факту совпадений в HTML
(`(сколько всего, сколько пометить, старое, новое)`) — сборка падает, если
разметка разошлась с ожиданием, а не вставляет бейдж не туда молча.

Затем каждый деплоится тем же `wrangler pages deploy <папка> --branch=<slug>`.
`build/` в `.gitignore`, пересобирается локально.

10. **Варианты компоновки hero** собраны и опубликованы (A/B выше) +
