## Что затрагивает контракты (по предварительной оценке)

- Каждая новая формулировка из колонки «Правка» — **новый owner-approved текст**: правка
  `scripts/client_copy_contract.py`, версия контракта, `docs/CONTENT-OWNER-EDITS.md`,
  прогон `verify-client-copy.py`. Frozen client source не трогается.
- Смена шрифта или начертаний — новые `@font-face` файлы в `site/fonts/`, `fonts.css`,
  повторный замер «0 фолбэков» на обоих вьюпортах.
- Поведение рабочего времени «везде» — `site-addons/action-bar/` (versioned, SemVer + дата
  во всех маркерах) и `site-addons/final-dev3/hero-business-hours.js` (или его наследник для dev4).
- Новый alias `final-dev4` — строка в `scripts/client-preview-map.json`; `final-dev3` остаётся
  как точка сравнения для владельцев.

## Открытые вопросы владельцу

1. **Шрифты.** Какие два? Оставить Playfair Display + Onest и добавить начертания Playfair
   (сейчас загружено только 500), или заменить пару? Пометка «Поменять шрифт» стоит на 14
   заголовках — это смена семейства или только начертания/размера?
2. **Фото.** Насколько уменьшить (высота 698 → ?) и менять ли пропорцию 4/5? Есть ли
   неурезанные оригиналы — без них выравнивать можно только опусканием Юлии.
3. **Формулировки.** Правки в колонке «Правка» считать утверждёнными дословно (owner override)
   или это черновики для обсуждения? Отдельно: 3.23 меняет юридическую фразу о судебном
   постановлении — подтверждает адвокат.
4. **Свайп тем на мобильном** — только жест, или плюс стрелки/точки-индикаторы?
5. **Карта по клику на адрес** — Google Maps ссылкой (уже есть `map-link` в контактах) или
   встроенная карта?
