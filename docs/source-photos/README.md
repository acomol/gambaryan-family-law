# Исходные фотографии

Оригиналы, извлечённые из первой версии сайта
(`https://meek-heliotrope-64c14a.netlify.app/`). Та страница собрана как
self-contained bundle: файлы лежат внутри `<script type="__bundler/manifest">`
в виде base64 под UUID-ключами, поэтому вытаскивались из манифеста, а не
скачивались по ссылкам.

Здесь хранятся **исходники**, а не то, что отдаётся браузеру. Всё, что уходит
в продакшн, лежит в `site/assets/` и собирается из этих файлов скриптами.

| Файл | Размер | Что это | Где используется |
|------|--------|---------|------------------|
| `alexander-portrait.jpg` | 2794×4284 | Поясной портрет, серый фон, руки скрещены | Карточка адвоката (`alexander-card-v2-*`) |
| `yulia-portrait.jpg` | 1122×1402 | Поясной портрет, серый фон | Карточка адвоката (`yulia-card-*`) |
| `duo-wide.jpg` | 2623×1605 | Студийный кадр вдвоём, кадрирован вплотную к фигурам | Мастер для hero (`grade-hero-photo.py`) |
| `duo-tall.jpg` | 2288×1855 | Тот же дубль, но с запасом над головами и по бокам | Не используется — см. ниже |
| `alexander-cutout.png` | 2002×1287 | Вырезанная фигура с альфа-каналом (78% прозрачных пикселей) | Баннер прецедента |

## duo-tall — нереализованная альтернатива

`duo-tall` — настоящий кадр с воздухом над головами. Сейчас hero собирается из
`duo-wide`, которому этот воздух дорисовывается скриптом
`scripts/extend-hero-canvas.py` (продление ровной кромки фона).

Переход на `duo-tall` убрал бы синтетическую достройку, но изменил бы
композицию: фигуры там стоят ближе к центру, а золотой блик слева слабее —
то есть под текстом hero остаётся меньше «воздуха со светом». Решение за
владельцем; переключение — это замена входного файла в
`scripts/grade-hero-photo.py` и пересчёт `object-position`.

## Пайплайн

```
docs/source-photos/duo-wide.jpg
  -> scripts/grade-hero-photo.py     # подсветить фигуры, не тронув чёрный фон
  -> scripts/extend-hero-canvas.py   # достроить холст сверху и справа
  -> site/assets/hero-duo-air-*, hero-duo-mob-*
```
