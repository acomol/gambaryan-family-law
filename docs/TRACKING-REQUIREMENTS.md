**Обновлено:** `2026-09-21`

final-dev5 (`docs/LAUNCH-LP-GAMBARIAN.md`). Метод и каталог ошибок —

к заявке, отслеживается. Что изменилось в v2: события пишет **код страницы** (dataLayer-first),

## 2. Архитектура

```
страница → dataLayer.push(карта §3)                 ← код, проверяется автотестом
   │
   ├─ форма → /api/lead → Albato → CRM/таблица       ← истина о заявке
   │            └─ 202 → generate_lead (1 раз на заявку)
   │
   └─ GTM (браузерный, только на lp.gambarian.com) → GA4, Google Ads   ← раздача, согласие
```

- **GTM не придумывает события.** Триггер — только «Custom Event равно <имя>»; ни кликов по
  адресу ссылки, ни regex (плейбук §11.1).
- **Теги работают только на `lp.gambarian.com`.** Превью на pages.dev доказывают, что событие
  попало в dataLayer, но не форвардинг и не конверсию (§9.3, E49). GTM Preview, DebugView и
  Tag Assistant — только на `lp`, с меткой внутреннего трафика.
- **Истина о заявке — строка в CRM** с тем же `submission_id`. Ответ `202` от `/api/lead`
  значит «Albato принял», не «человек увидел» (E33).

## 4. Словарь событий

Общий параметр на **каждом** событии: `design_version` = `final-dev5` (менять при каждом
редизайне). Запрещено: имя, телефон, e-mail и любые данные формы в событиях (P7);
зарезервированные параметры GA4 `source`, `medium`, `campaign` (E02).

| Событие | Когда пушится | Параметры | Уровень |
|---|---|---|---|
| `generate_lead` | `/api/lead` ответил 202 на **новую** заявку | `form_id`, `submission_id` (→ ID транзакции в Ads), `seconds_to_lead` | MACRO |
| `lead_corrected` | успешное исправление контактов после заявки | `submission_id`, `corrects_submission_id` | FUNNEL |
| `form_error` | ошибка полей или отправки | `form_id`, `error_type` (`validation`/`unavailable`/`network`/`server`), `http_status` | FUNNEL |
| `form_start` | первый ввод в любое поле | `form_id` | NOISE |
| `form_confirm` | показан шаг проверки контактов | `form_id` | FUNNEL |
| `form_correct` | «Исправить» на шаге проверки | `form_id` | FUNNEL |
| `contact_click` | клик по `tel:`, `wa.me`, Google Maps, «Записаться» в панели | `method` (`phone`/`whatsapp`/`google_maps`/`form_anchor`), `placement`, `business_state` (`open`/`closed`) | MICRO |
| `form_anchor_click` | клик по ссылке на `#contact` | `placement`, `service`, `attorney` | FUNNEL |
| `nav_click` | пункт меню шапки, мобильного меню, подвала | `target`, `placement` | FUNNEL |
| `service_select` | смена темы в услугах | `service`, `via` (`tab`/`swipe`/`dot`/`arrow`/`footer`) | FUNNEL |
| `section_view` | блок наполовину в кадре, раз за просмотр | `section` | FUNNEL |
| `scroll_depth` | 25 / 50 / 75 / 90 % | `percent` | FUNNEL |
| `time_on_page` | 30 / 60 / 120 / 180 с видимого времени | `seconds` | FUNNEL |

`placement` = блок, где стоит элемент: `header`, `menu`, `hero`, `services`, `precedent`,
`attorneys`, `contacts`, `form_error`, `footer`, `action_bar`. Берётся из ближайшего блока
страницы, а не из текста ссылки.

## 5. Google Ads

| Конверсия | Событие | Статус в Ads | Счёт |
|---|---|---|---|
| Заявка | `generate_lead` | основная | одна на клик; ID транзакции = `submission_id` |
| Обращение в WhatsApp | `contact_click` {whatsapp} | отдельная цель (решение 5) | одна на клик |
| Звонок из объявления | Google, номер переадресации | основная (решение 6, потом не понизить) | звонок ≥ 60 с |
| Клик по телефону на сайте | `contact_click` {phone} | вторичная (наблюдение) | одна на клик |
| Квалифицированная заявка | из CRM по `gclid` | этап 4: основная вместо «Заявки» | — |

- **Enhanced conversions — не из браузера.** Телефон и e-mail в dataLayer не кладём (P7);
  сопоставление по хешу — позже, с сервера или выгрузкой из CRM (этап 4).
- **Ремаркетинг запрещён.** Google относит «Divorce services» к категории «Relationship
  hardships»: нельзя Customer Match, аудитории по посетителям сайта, расширение аудиторий,
  похожие сегменты ([категория](https://support.google.com/adspolicy/answer/16700849),
  [политика](https://support.google.com/adspolicy/answer/143465)). Учёт конверсий не ограничен.
  Пункт о ретаргетинге из `clients/gambarian/PPC-LAUNCH-CHECKLIST.md` для Google снят.
- Конверсии Ads считаются в своих единицах (GAQL), не в событиях GA4 (E54).

## 7. GA4

- Ресурс — решение 1. Пользовательские параметры: `method`, `placement`, `business_state`,
  `service`, `via`, `section`, `percent`, `seconds`, `error_type`, `target`, `attorney`,
  `design_version` (без регистрации параметр в отчётах не виден, E06).
- Ключевое событие: `generate_lead` — звёздочкой на уже собранном событии (E04).
- Автосбор: выключить «исходящие клики», «взаимодействия с формами», «прокрутку», «поиск по
  сайту» (дубли и ложные события, E05); просмотры страниц оставить.
- Внутренний трафик: cookie → параметр `traffic_type` → фильтр, не по IP.
- Хранение данных 14 месяцев. Связь аудиторий с Ads не создавать (§5).

## 8. Согласие

- Политика согласия Google для ЕС действует только для EEA, Великобритании и Швейцарии
  ([источник](https://www.google.com/about/company/user-consent-policy/)) — к Израилю не
  относится.
- Consent Mode v2 по регионам: для EEA/UK/CH четыре сигнала `denied` по умолчанию, для
  остальных `granted`. Тег значения по умолчанию срабатывает на Consent Initialization —
  раньше всех тегов (Google считает «не выставлено» как «разрешено», E19). Баннера нет,
  поэтому посетители из ЕС не измеряются — это допустимо.
- Израильская поправка 13 — **не проверено**, решение 8.
