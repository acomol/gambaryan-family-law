# Нижняя панель: что смотреть вручную и как снять код

Чего не хватает после двух заходов исследования: **пиксельные пороги, задержки и
сами триггеры показа/скрытия**. Всё это живёт в минифицированных чанках и из
серверного HTML не достаётся. Плюс 29 сайтов вообще не открылись — антибот или
клиентский рендер.

Здесь два готовых сниппета для консоли браузера и список адресов по приоритету.

---

## Как открывать

Chrome на компьютере, не телефон — с телефона код не скопировать.

1. `F12` → значок телефона в левом верхнем углу панели (`Ctrl+Shift+M`)
2. В выпадающем списке устройств выбрать **iPhone 12 Pro** (390×844)
3. **Перезагрузить страницу** — многие сайты решают, показывать панель, только при
   загрузке, и без перезагрузки её не будет
4. Открывать **карточку товара или услуги**, а не главную. Панели живут именно там

## Сниппет 1 — что вообще есть внизу экрана

Вставить в консоль (вкладка Console), нажать Enter. Результат сам копируется в
буфер обмена — присылайте как есть.

```js
copy([...document.querySelectorAll('*')].filter(el => {
  const s = getComputedStyle(el), r = el.getBoundingClientRect();
  return (s.position === 'fixed' || s.position === 'sticky')
    && r.bottom > innerHeight - 140 && r.width > innerWidth * 0.5
    && r.height > 16 && r.height < 220;
}).map(el => {
  const s = getComputedStyle(el), r = el.getBoundingClientRect();
  return {
    селектор: el.tagName.toLowerCase() + (el.id ? '#' + el.id : '') +
              (typeof el.className === 'string' && el.className
                 ? '.' + el.className.trim().split(/\s+/).join('.') : ''),
    высота: Math.round(r.height),
    zIndex: s.zIndex,
    позиция: s.position,
    переход: s.transition,
    трансформ: s.transform,
    отступСнизу: s.paddingBottom,
    видимость: s.visibility + ' / ' + s.opacity + ' / ' + s.display,
    действий: el.querySelectorAll('a,button').length,
    разметка: el.outerHTML.slice(0, 600)
  };
}));
```

Если буфер пуст — значит нижней панели на этой странице нет, это тоже результат.

## Сниппет 2 — главное: поймать триггер и порог

Это то, ради чего всё затевается. Сниппет следит за панелью и записывает
**каждое** изменение её состояния вместе с тем, сколько пикселей было пролистано
и в какую сторону.

Сначала подставьте селектор из первого сниппета вместо `ВАШ_СЕЛЕКТОР`:

```js
(() => {
  const el = document.querySelector('ВАШ_СЕЛЕКТОР');
  if (!el) return console.warn('элемент не найден — проверьте селектор');
  const snap = () => {
    const s = getComputedStyle(el);
    return { класс: el.className, трансформ: s.transform, прозрачность: s.opacity,
             display: s.display, visibility: s.visibility, высотаМакс: s.maxHeight,
             низ: s.bottom };
  };
  let prev = JSON.stringify(snap());
  let yПриПрошломИзменении = scrollY, прошлыйY = scrollY, направление = '—';
  window.__log = [];
  addEventListener('scroll', () => {
    направление = scrollY > прошлыйY ? 'вниз' : (scrollY < прошлыйY ? 'вверх' : '—');
    прошлыйY = scrollY;
  }, { passive: true });
  new MutationObserver(() => {
    const s = snap(), j = JSON.stringify(s);
    if (j === prev) return;
    window.__log.push({
      ...s, направление,
      прокрутка: Math.round(scrollY),
      пикселейСПрошлогоИзменения: Math.round(Math.abs(scrollY - yПриПрошломИзменении)),
      время: Math.round(performance.now())
    });
    prev = j; yПриПрошломИзменении = scrollY;
  }).observe(el, { attributes: true, attributeFilter: ['class', 'style'] });
  console.log('%cЗапись пошла. Полистайте вниз, потом вверх, потом снова вниз — медленно и рывками.',
              'color:#f0ae1f;font-weight:bold');
  console.log('Потом выполните:  copy(JSON.stringify(__log, null, 1))');
})();
```

**Что делать после запуска:**

1. Медленно пролистать вниз на пару экранов
2. Медленно вернуться вверх
3. Резко бросить вниз до конца страницы
4. Открыть меню-бургер, закрыть
5. Поставить курсор в любое поле ввода
6. Выполнить `copy(JSON.stringify(__log, null, 1))` и прислать

Колонка **`пикселейСПрошлогоИзменения`** и есть искомый порог. Если панель
реагирует на первое же движение — порога нет. Если стабильно на 40, 60, 100 —
это их константа.

**Оба сниппета проверены на нашей собственной панели** — работают, вывод
осмысленный. Одна особенность, которую надо знать при чтении результата:
`класс` меняется мгновенно, а `трансформ` и `прозрачность` в той же строке
показывают ещё **старое** значение — наблюдатель срабатывает до того, как
браузер применит переход. Источник истины — колонка `класс`; остальное читать со
сдвигом на строку. Это не мешает, но иначе картинка выглядит перевёрнутой.

### Приоритет 2. Один незакрытый вопрос

**oliveyoung.co.kr** — единственный сайт на всей выборке, где панель уезжает вниз
через `transform: translateY(100%)`, но **что именно ставит класс `.hide`, найти
не удалось** — обработчик в ленивом чанке.

Селектор для второго сниппета: `.dock-bar`

Если там окажется скролл-триггер — это будет единственный подтверждённый пример
в мире, делающий то же, что и мы. Самая ценная точка списка.

### Приоритет 4. Если попадётся под руку

Любой сайт, где вы **сами** замечаете удачную нижнюю панель — снимайте обоими
сниппетами. Выборка перекошена в сторону того, что технически доступно, а не
того, что хорошо сделано.

## Что мне присылать

Минимум — вывод первого сниппета. Он даёт селектор, высоту, слой, анимацию и
разметку.

Максимум и самое ценное — вывод второго: он показывает **поведение**, а не код.
Пороги, направление, задержки. Это ровно та дыра, которую без живого браузера не
закрыть.

Если сниппет не сработал или консоль ругается — присылайте текст ошибки, поправлю.
