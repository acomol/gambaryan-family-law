# Четыре шрифтовых набора для лендинга

**Статус:** подготовка. Ничего, кроме варианта 1, на сайте не внедрено.
**Задача:** показать клиенту вживую, как меняется лендинг с разными шрифтами.

Все шрифты — Google Fonts, бесплатные, кириллица подтверждена по официальному
CSS API (проверялся сам файл, не название). Вес указан для кириллического
поднабора — того, что фактически скачает русскоязычный посетитель.

## Наборы

| № | Название | Заголовки | Текст | Вес кир. набора |
| :---: | --- | --- | --- | ---: |
| 1 | Нынешний | Playfair Display | Onest | 34,4 КБ |
| 2 | Спокойный классический | Lora | Inter | 39,0 КБ |
| 3 | Экранный, максимум читаемости | Literata | Manrope | 34,6 КБ |
| 4 | Как на профильном рынке | PT Serif | Golos Text | 63,5 КБ |

Разброс по весу между наборами ~5 КБ (кроме четвёртого) — на скорость выбор
практически не влияет, решать можно по виду.

### Вариант 1 — Playfair Display + Onest (нынешний)

Высококонтрастный заголовочный serif: тонкие волосяные штрихи рядом с жирными
основными. Читается как «дорогая частная практика», близко к журнальной подаче.

**Риск:** на мобильном тонкие штрихи местами исчезают. Приём массово используется
в бьюти и моде — для юриста может звучать декоративно.

| Роль | Шрифт | Переменный | Вес |
| --- | --- | --- | ---: |
| Заголовки | Playfair Display | да, 400–700 | 20,6 КБ |
| Текст | Onest | да, 400–800 | 13,8 КБ |

### Вариант 2 — Lora + Inter

Lora — serif умеренного контраста с лёгкими каллиграфическими корнями, выглядит
солидно и «по-адвокатски», без модного налёта. Inter — выверенный интерфейсный
гротеск с отличной кириллицей, спроектирован под экраны.

Связка serif в заголовках + гротеск в теле текста — та же схема, что у всех
профильных площадок, но без риска тонких штрихов.

| Роль | Шрифт | Переменный | Вес |
| --- | --- | --- | ---: |
| Заголовки | Lora | да, 400–700 | 20,7 КБ |
| Текст | Inter | да, 100–900 | 18,3 КБ |

### Вариант 3 — Literata + Manrope

Literata нарисована Google для чтения с экрана (шрифт Google Play Books): крупное
очко, короткие выносные, спокойные засечки. Manrope — геометричный гротеск, чуть
теплее Inter, с сильной кириллицей.

Самый «незаметный» набор — не спорит с содержанием и лучше других держит длинные
абзацы вроде описания прецедента. Ставка не на образ, а на дочитывание.

| Роль | Шрифт | Переменный | Вес |
| --- | --- | --- | ---: |
| Заголовки | Literata | да, 200–900 | 20,5 КБ |
| Текст | Manrope | да, 200–800 | 14,1 КБ |

### Вариант 4 — PT Serif + Golos Text

Не подбор по вкусу, а то, что реально стоит у профильных площадок: PT Serif — на
сайте юрфирмы ALRUD, Golos Text — на Право.ru. Оба нарисованы в Паратайпе **под
кириллицу**, а не с кириллицей-приложением к латинице: пропорции и ритм рассчитаны
на русский текст.

**Цена:** PT Serif непеременный — нужны два отдельных файла вместо одного, набор
тяжелее остальных примерно на 25 КБ.

| Роль | Шрифт | Переменный | Вес |
| --- | --- | --- | ---: |
| Заголовки | PT Serif 400 | нет | 21,6 КБ |
| Заголовки | PT Serif 700 | нет | 20,4 КБ |
| Текст | Golos Text | да, 400–900 | 21,5 КБ |

## Замер рынка (август 2026)

Вытянут CSS профильных площадок — что там стоит на самом деле, а не по статьям.

| Сайт | Заголовки + текст | Доступность |
| --- | --- | --- |
| **Право.ru** — юридический портал №1 | Golos Text | Google Fonts |
| **ALRUD** — юридическая фирма | PT Serif + PT Sans | Google Fonts |
| **ЕПАМ** — юрфирма топ-1 РФ | Georgia + Roboto | системный + Google |
| **Адвокатская газета** | Noto Serif + Noto Sans | Google Fonts |
| Пепеляев Групп | Geometria | платный |
| Тинькофф Журнал | Charter + Graphik | платные |
| Бюро Горбунова | Bureausans / Bureauserif | собственные |
| Хабр | Fira Sans + Inter | Google Fonts |

Выводы из замера:

- **Все четыре профильные юридические площадки используют связку serif + гротеск** —
  ровно ту схему, по которой построены все четыре набора. Это совпадение поведения
  рынка, а не вывод из статей.
- **Ни одна не берёт высококонтрастный display-serif** вроде Playfair. Только
  текстовые serif умеренного контраста: PT Serif, Georgia, Noto Serif.
- **Платные шрифты — только там, где есть бюджет на шрифтовой заказ** (медиа,
  дизайн-бюро). У юридических фирм — бесплатные. Ограничение «только Google Fonts»
  для этого сегмента норма, а не компромисс.
- **Одинаковое имя ≠ одинаковое покрытие.** Госуслуги используют Lato, у которого
  на Google Fonts кириллицы нет вовсе. Их файл проверен напрямую: 255 кириллических
  глифов — они хостят другой билд. Название ничего не гарантирует, проверять надо файл.
- **По весу мы аккуратнее крупного портала.** Госуслуги отдают Lato целиком —
  178 КБ на одно начертание. Наш кириллический поднабор — 14 КБ.

## На что смотреть при выборе

- **Строка с цифрами** «30+», «054-549-0623» и «Ёлка ЩУКА зыбь» — там видны и
  кириллические формы, и то, как шрифт держит цифры. В блоке фактов цифра крупная,
  это самое заметное место набора.
- **Телефон обязательно.** Тонкие штрихи Playfair на светлом фоне при мелком кегле
  теряются заметнее, чем на десктопе.
- **Все шрифты, кроме PT Serif, переменные** — одно обращение покрывает все нужные
  насыщенности (400/500/600/700/800) без синтетического жирного.

## Рекомендация

**Вариант 4 (PT Serif + Golos Text)** — после замера рынка первый в списке. Ровно
то, что стоит у ALRUD и Право.ru, оба шрифта нарисованы под кириллицу. Плата —
лишние 25 КБ и непеременный serif; на скорость влияет слабо.

**Вариант 2 (Lora + Inter)** — тот же жанр, но мягче и легче: Lora умеренного
контраста не рассыпается на мобильном, Inter — самый проверенный экранный гротеск.

**Вариант 3** — если приоритет в том, чтобы длинные тексты дочитывали до конца.

**Вариант 1** оставлять только если «журнальный» образ — сознательная часть
позиционирования: в юридическом сегменте так не делает никто.

Финально это решается замером. После выбора двух фаворитов имеет смысл A/B-тест —
при текущем трафике это реальный, а не теоретический эксперимент.

## Техническая реализация

Шрифты заведены токенами в `site/styles.css`:

```css
--font-serif: "Playfair Display", Georgia, "Times New Roman", serif;
--font-body:  "Onest", Helvetica, Arial, sans-serif;
--font-narrow: var(--font-body);
```

Смена набора — это подмена трёх токенов плюс `@font-face` и файлы `.woff2` в
`site/fonts/`. Вёрстка не затрагивается.

Кириллические поднаборы берутся из официального CSS API с браузерным User-Agent:

```bash
curl -A "<browser UA>" "https://fonts.googleapis.com/css2?family=Lora:wght@400..700&display=swap"
# → в ответе блок /* cyrillic */ с прямой ссылкой на .woff2
```
